💾 Backup e restauração

    

      Importante: turmas, alunos, provas, gabaritos e resultados ficam salvos no navegador deste aparelho.
      O backup permite recuperar essas informações se você trocar de celular/computador, mudar de navegador ou limpar os dados.
    


    

      

        
⬇️ Fazer backup

        
Baixa um único arquivo .json com os dados do aplicativo. Se houver PDF/Word anexado às provas, ele também será incluído.

        
      


      

        
⬆️ Restaurar backup

        
Escolha um arquivo de backup salvo anteriormente. A restauração substituirá os dados atuais deste navegador.

        
        
      

    


    

    

  


  

    
O que entra no backup?

    
✅ Turmas   ✅ Alunos   ✅ Provas   ✅ Gabaritos   ✅ Resultados/correções   ✅ Arquivos PDF/Word anexados às provas

    
Guarde o arquivo de backup em um local seguro, como Google Drive, OneDrive, pendrive ou computador.
